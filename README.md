## Description

This is a project which I built to track my progress on my daily as well as weekly goals. it has four main features which are
1. Accept daily, weekly and monthly goals.
2. Track progress to achieving the goals.
3. Generate report.
4. Rank me against past versions of me.

## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# development
$ docker compose up
```
